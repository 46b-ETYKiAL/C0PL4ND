# Third-Party Licenses

C0PL4ND bundles or links the following third-party assets and code. The full
per-font license text is reproduced next to each font under
`crates/app/assets/fonts/<Font>/`; this document is the discoverable index.

## Fonts

All bundled display/mono faces are redistributed under the SIL Open Font
License 1.1 (OFL-1.1) — which permits bundling in a software product with
attribution — except **Syncopate**, which Google Fonts ships under Apache-2.0.
Each font's full license text sits beside the `.ttf` in its font directory.

## Rust Dependencies

The transitive dependency inventory is published with each release as a
**CycloneDX SBOM** (`*.cdx.json`, generated by `cargo-cyclonedx` in the release
workflow and attached to the GitHub Release), which records the license of every
Cargo dependency. The allow-list / rejection rules are enforced in CI via
[`deny.toml`](deny.toml) (`cargo deny check`), so a dependency with a
non-allow-listed license blocks the build. C0PL4ND's own code is dual-licensed
MIT OR Apache-2.0 ([`LICENSE-MIT`](LICENSE-MIT) / [`LICENSE-APACHE`](LICENSE-APACHE)).

> **Correction.** This section previously said the inventory was generated "via
> `cargo-about`". It is not: `cargo-about` is not installed or invoked anywhere
> in this repository's CI, and there is no `about.toml`. The SBOM described above
> is what is actually produced and published.

## Where the license texts are delivered

Every release artifact — the portable `.tar.gz` / `.zip`, the `.deb`, the
AppImage, the `.app`/`.dmg`, and the Windows installer payload — carries a
`licenses/` tree staged by
[`packaging/collect-licenses.sh`](packaging/collect-licenses.sh), containing the
full text of every embedded font license, alongside `LICENSE-MIT`,
`LICENSE-APACHE`, and this document.

This matters because the typefaces above are `include_bytes!`-embedded into the
executable itself, and OFL-1.1 §2 requires the license text to accompany every
copy of the Font Software. Before this was wired, **no release artifact carried
any font license text at all** — the packaging steps copied only `LICENSE-MIT`,
`LICENSE-APACHE` and `README.md`, on a best-effort basis that silently shipped
nothing when a file was absent. A release-blocking gate
([`packaging/verify_license_delivery.py`](packaging/verify_license_delivery.py))
now fails the build if any artifact path stops staging these texts.

## License Compatibility

All bundled third-party licenses (MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib,
Unicode-3.0, MPL-2.0, OFL-1.1, Ubuntu-font-1.0) are permissive and compatible
with C0PL4ND's own MIT OR Apache-2.0 dual license. No GPL-licensed code is
bundled or linked.
